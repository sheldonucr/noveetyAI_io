The shift

Physics is now a first-order design constraint

IR-drop drives Joule heating. Heat drives electromigration. CTE mismatch drives warpage. Analyzed separately and checked last, each answer misleads — and the fix arrives when it is most expensive to make.

"The physics is coupled."

In an advanced package, a flow that analyzes each domain in isolation is describing a chip that doesn't exist.

Larry Williams · Synopsys Semiconductor Digest ↗

Sign-off doesn't scale

Direct transient solves and full 3D FEM runs cost minutes each. A design-space search needs thousands of evaluations.

Domains feed each other

Each effect drives the next. Solved in isolation, every individual answer is wrong about the package as built.

Agents need callable physics

An autonomous design agent can only optimize what it can invoke. GUI-bound analysis cannot close the loop.

What this cost on real silicon, and how each coupled effect maps to an engine — the full case.

How it works

An engineered loop, not a prompted one

A human sets the objectives, the budget and the stopping condition once. After that the loop runs unattended — proposing candidates in parallel, evaluating each against real physics, and verifying with a separate agent before anything is signed off.

CLI-first

Every analysis is scriptable. Nothing in the loop needs a GUI.

Structured I/O

Machine-readable inputs; fields, margins and hotspots out.

Flow-agnostic

Plugs into any agentic orchestration layer you already run.

Closed-loop

Optimize against real physics, not a surrogate proxy.
